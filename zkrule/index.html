The auditor can't read the message. How does it know whether it mentions “Ming”?审核机构看不到消息内容，怎样知道里面有没有“小明”？

Alice sends Bob an end-to-end encrypted message. A public rule says one word must not appear in it. The auditor holds only the ciphertext and a zero-knowledge proof from Alice — no key, no plaintext. Step through how the message is encrypted, how the proof ties “does the text contain the word?” to that exact ciphertext, and how the auditor, from ciphertext and proof alone, becomes certain the word is there while learning nothing else.Alice 给 Bob 发了一条端到端加密的消息。按规定，消息里不能出现某个词。审核机构手里只有密文和 Alice 附上的零知识证明，没有密钥，也看不到原文。下面一步步演示：消息怎样被加密，证明怎样把“原文是否含有违禁词”这一件事绑定到密文上，审核机构又怎样只凭密文和证明，确认里面确实有这个词，而对其余内容一无所知。

What the auditor ends up knowing审核机构最终知道了什么
  • One bit — hit or no hit — plus the message length. Not where the word appears, not how often, and none of the other text.只有“命中 / 未命中”这一位，以及消息长度。它不知道违禁词出现在哪里、出现了几次，也看不到其余文字。
  • Every wire value it opens during a spot check is masked with fresh randomness, so on its own it is just a random number. Each round in which every checked gate holds halves a cheater's chance of slipping through.它抽查时打开的每个线值都事先加了随机遮掩，单独看只是随机数；而每一轮被抽查的门都对得上，作弊者漏网的概率就会减半。
  • The full system proves the encryption, the message format and the rule check together in one proof, about 0.05 s per short message, using our proprietary acceleration techniques.完整的系统在同一个证明里覆盖 AES-256-GCM 加密、带盐承诺、文本格式检查和全文规则扫描，每条短消息约 0.05 秒。

The auditor can't see the photo. How does it know whether it shows a dog?审核机构看不到照片，怎样知道里面是不是狗？

Alice sends Bob an encrypted photo. A public rule says images of dogs must not be sent. The auditor holds only the ciphertext and a zero-knowledge proof from Alice — no key, no pixels. Step through how the original image is encrypted in full, how the proof runs a public image classifier on exactly those encrypted pixels, and how the auditor, from ciphertext and proof alone, learns whether the image shows a dog and nothing else.Alice 给 Bob 发送一张加密的照片。按公开规则，不能发送狗的图片。审核机构手里只有密文和 Alice 附上的零知识证明，没有密钥，也看不到像素。下面一步步演示：原图怎样被整张加密，证明怎样在这份加密的像素上运行公开的图像分类模型，审核机构又怎样只凭密文和证明，得知图片里是否有狗，而对图片的其余内容一无所知。

What the auditor ends up knowing审核机构最终知道了什么
  • One bit — dog or no dog — plus the image's width and height. The pixels, the file type and the metadata stay hidden; metadata never leaves Alice's device.“是狗 / 不是狗”这一位，以及图片的宽和高。像素、文件类型和元数据都看不到；元数据根本不离开 Alice 的设备。
  • The classifier is public and registered by its hash. The proof binds its result to exactly the encrypted image Bob receives, so Alice cannot pair one image with another picture's result; a different image, key or result makes the proof fail.分类模型公开并以哈希登记。证明把模型的结论绑定到 Bob 收到的那张加密图片上，所以 Alice 无法把一张图和另一张图的结论拼在一起；换图、换密钥或谎报结果，证明都不成立。
  • One proof covers the whole image Bob receives, the encryption and the classifier. With our proprietary acceleration techniques, an 800 × 800 photo takes about 22 s on a desktop PC, and a 4-megapixel photo about 2 minutes.一份证明覆盖 Bob 收到的整张图片、加密以及分类模型。借助我们自有的加速技术，在台式机上 800 × 800 的照片约 22 秒，400 万像素的照片约 2 分钟。

    How it works工作原理

    Every message and image goes through the same three steps. The auditor never holds a decryption key.每条消息、每张图片都经过同样的三步。审核方从不持有解密密钥。

    1Encrypt加密

    Alice's device encrypts the content, for an image the original at full resolution, with a fresh key that only Bob can recover. Only the ciphertext C leaves the device.Alice 的设备用新生成的密钥加密内容（图片是原始分辨率的整张原图），只有 Bob 能取回这把密钥。离开设备的只有密文 C。

    2Prove证明

    Inside a zero-knowledge circuit, the device evaluates the public rule on the plaintext and proves that this plaintext is exactly what C encrypts. For images, the circuit runs a public image classifier on the decrypted image, so the check covers the whole image Bob will receive.设备在零知识电路中对明文执行公开规则，并证明这段明文正是 C 加密的内容。对于图片，电路对解密出的图片运行公开的图像分类模型，所以检查覆盖 Bob 将收到的整张图片。

    3Verify验证

    The auditor checks the proof against C and the rules. It learns one bit: whether a rule matched. A false claim cannot pass verification, and matching content is not delivered.审核方对照 C 和规则验证证明，只得到一位信息：是否命中规则。虚假的声明无法通过验证，命中规则的内容不会被送达。
